# RIGI Project Instructions

## Product intent

Maintain a cinematic, premium, image-led website for RIGI Home & Garden Design LLC. Preserve the modern California architectural character and avoid generic corporate-template styling.

## Implementation guardrails

- Do not redesign established sections without explicit approval.
- Preserve the scroll-driven Canvas hero, GSAP ScrollTrigger behavior, branding, CTA links, reverse scrolling, and final-frame hold.
- Keep hero frames in `public/frames/rigi` with continuous three-digit numbering.
- Store brand assets in `public/brand`.
- Store project imagery by location in `public/projects/california`, `public/projects/dubai`, and `public/projects/germany`.
- Store source video assets in `public/video` and project utilities in `scripts`.
- Keep documentation current in `docs` when structure or content direction changes.
- Run `npm run build` after implementation changes.
